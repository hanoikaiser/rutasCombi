Bienvenido al Sistema

Este proyecto busca optimizar la movilidad urbana de Arequipa mediante el uso de tecnología de geolocalización y datos de transporte.

Aquí podrás visualizar, editar y analizar rutas de transporte público de forma interactiva, además de conocer las conexiones más eficientes entre diferentes puntos de la ciudad.

¿Qué es este sistema?

Este sistema permite a los administradores y planificadores del transporte público visualizar, editar y gestionar rutas en un mapa interactivo. Está diseñado para mejorar la experiencia de los ciudadanos, ofreciendo rutas más eficientes y actualizadas.

Funciones principales

  • 📍 Visualización de rutas existentes con detalles de cada tramo.
  • 🛠️ Editor interactivo para modificar trayectos directamente en el mapa.
  • 💾 Gestión de base de datos que guarda y actualiza la información de cada ruta.
  • 🚍 Búsqueda de rutas según origen y destino.
  • 🌍 Visualización geográfica usando Leaflet y OpenRouteService API.
